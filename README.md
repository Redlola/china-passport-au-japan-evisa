# 澳洲申请日本 eVISA 助手模板

在线使用：https://redlola.github.io/china-passport-au-japan-evisa/

给在澳洲、拿中国护照的人申请日本电子签证（JAPAN eVISA）用的信息模板和 AI 提示词。ChatGPT、豆包、Claude 等任何 AI 都能用。

## 有什么用

把信息表填好，连同提示词一起发给 AI，AI 会：

1. 检查你的材料有没有问题：机票有没有 PNR、银行流水是不是 3 个月、学生有没有交在读证明等
2. 生成英文行程表 Schedule of Stay，可以直接导出 PDF 上传
3. 按 eVISA 网站的顺序告诉你每一栏填什么，日期、电话格式都已经写好
4. 提交前提醒你容易出错的地方

## 怎么用

1. 打开 [info-template.md](info-template.md)，复制全部内容，把表格填好。护照号、身份证号、银行卡号不用填，到网站上自己输入。
2. 打开 [prompt.md](prompt.md)，复制分割线以下的提示词。
3. 把提示词和填好的信息表一起发给 AI。
4. 按 AI 的输出准备材料、填 eVISA 网站：https://www.evisa.mofa.go.jp

## 适合谁

学生（500）、上班族（482 / 485 / PR 在职）、打工度假（417 / 462）、做生意、没有工作、持过桥签的申请人。用澳洲护照的澳洲公民短期旅游不需要日本签证。

## 里面写了

- 所有要用的官网：eVISA、珀斯领事馆签证要求、VEVO、Visit Japan Web、全日空
- 按申请人类型分的材料要求
- 怎么在航空公司官网先不付全款拿到 PNR
- 照片避坑（美颜滤镜、文件大小实测）
- 被退回、撤回后怎么重新交

## 注意

- 内容按珀斯日本总领事馆官网和我自己的申请经验整理，规则可能会变，以领事馆官网为准：https://www.perth.au.emb-japan.go.jp/itpr_ja/11_000001_00495.html
- 其他州的申请人请看自己所在州日本领事馆的要求。
- 不要把护照号、身份证号、银行卡号发给 AI 或任何人。
- 这不是官方文件，也不是签证代办服务。
