# 日本 eVISA 旅行准备助手

在线使用：https://redlola.github.io/china-passport-au-japan-evisa/

面向在澳洲的中国护照持有人。复古旅行海报风格，支持手机与桌面。

## 实际功能与边界

- 整理个人资料、航班、住宿和每日活动，生成英文行程表。使用浏览器打印对话框保存 PDF；不提供 PDF 合并。
- 本地读取文字型 PDF 的前 15 页。PNR 与手动输入号码进行文字匹配，不能验证预订有效性。
- 银行文件仅提示提取到的日期范围、姓名、地址片段和余额关键词。不能确定账单周期、余额日期、资金是否充足或是否符合签证要求。
- 图片和扫描 PDF 不做 OCR；护照扫描件不会自动填表。
- 生成供浏览器 AI 使用的指令；本站不连接 AI，不自动操作官网、上传或提交。工具能否完成操作取决于权限、登录及官网限制。
- 可选护照号会出现在指令和字段对照表中，仅保留于当前页面，不写入自动保存或 JSON 备份。刷新后需重填。

## 隐私

普通表单保存在浏览器 localStorage，导出 JSON 也含个人信息。共享电脑使用后请清空。文件在本地读取，不主动上传。PDF.js 及其 worker 从 Cloudflare CDN 加载，会向 CDN 发出网络请求。把指令或文件发给 AI 后，数据受该第三方政策约束；分享前请核对内容。最终提交由申请人亲自确认。

## 官方要求

2026-10-21 核对珀斯领事馆页面：银行材料包括最近三个月交易记录、一个月内余额日期、全名及西澳住址；航班须已确认，未要求必须已付款。页面没有将六位 PNR 单独列为强制要求。
https://www.perth.au.emb-japan.go.jp/itpr_ja/11_000001_00495.html

其他州请核对所属领事馆；本工具不是官方网站或签证合规审核。
