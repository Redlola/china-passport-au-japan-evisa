# 澳洲申请日本 eVISA 助手

在线使用：https://redlola.github.io/china-passport-au-japan-evisa/

给拿中国护照、在澳洲申请日本电子签证（JAPAN eVISA）的人用。填一次信息，网页帮你检查文件、生成材料，再生成一段"填表指令"，交给能操作浏览器的 AI，让它在 eVISA 官网上帮你填表。

## 整个流程

| 步骤 | 谁来做 | 做什么 |
| --- | --- | --- |
| 1. 填信息 | 你 | 在网页上选身份（学生 / 上班族 / 打工度假等），填护照信息、行程、住宿、每天去哪里 |
| 2. 检查文件 | 网页 | 把机票、银行流水、VEVO、在读证明、照片拖进网页，在你电脑上本地检查：机票有没有 PNR、流水是不是 1 个月内且有 3 个月记录、地址对不对、照片尺寸和大小 |
| 3. 生成材料 | 网页 | 英文行程表一键存 PDF；按身份列出要交的材料；列出 eVISA 网站每一栏填什么 |
| 4. AI 填表 | AI | 复制网页生成的"填表指令"，发给能操作浏览器的 AI（Claude in Chrome、ChatGPT Agent 等），它会打开官网逐栏填写、上传文件，停在确认页 |
| 5. 检查、提交 | 你 | 自己输入护照号，核对一遍，在申请列表点 Submit |

## 隐私

- 网页是纯静态页面，所有内容只保存在你自己的浏览器里，不会上传到任何服务器。
- 文件检查在你的电脑上完成，文件不会离开你的电脑。
- 护照号、身份证号、银行卡号不需要在网页上填，也不会写进给 AI 的指令里，到官网上自己输入。
- 给 AI 的指令要求它：只在官网 www.evisa.mofa.go.jp 操作、遇到护照号停下、不点最后的提交按钮。

## 不用网页也可以

- [info-template.md](info-template.md)：信息模板，可以离线填
- [prompt.md](prompt.md)：通用提示词，连同信息模板发给 ChatGPT / 豆包 / Claude，让 AI 检查材料、生成行程表、列出每一栏填什么

## 里面写了的坑

- 机票必须从澳洲出发、回澳洲；要有航空公司 PNR，但不要求已付款，网页里有不付全款拿 PNR 的方法
- 银行流水：户名、西澳现住址、最近 3 个月记录、余额日期在 1 个月内
- 学生签必须交在读证明，不收 COE，有效学生卡可以
- 照片不能美颜、加滤镜，网站没公布大小上限，实测约 120KB 能传、约 160KB 被拒
- 日期 YYYYMMDD、电话不能带 "+"、照片要手动框住整个头
- 申请被退回后不能修改，要新建；撤回后要等领事馆批准才能交新申请；不要在两个标签页同时打开官网

## 注意

- 按日本驻珀斯总领事馆官网和我自己的申请经验整理，规则可能变化，以领事馆官网为准：https://www.perth.au.emb-japan.go.jp/itpr_ja/11_000001_00495.html
- 其他州的申请人请看所在州日本领事馆的要求。
- 这不是官方网站，也不是签证代办服务。AI 填完后请务必自己核对再提交。
